# agy-NOV — 100% Native Modular Super-Workbench for Antigravity 2.0

`agy-NOV` (v0.7.0) unifies 13 high-demand Google Antigravity 2.0 workflows into one strictly official native plugin (Zero ASAR, Zero CDP) organized by a **4+1 functional domain IA** (Core Essentials `core` / Engineering Pipeline `pipeline` / On-Demand Toolbox `toolbox` / Opt-In Connectivity `connectivity` + **L0 Workflow Hub**), featuring adaptive wide/narrow navigation (`< 720px` 4-control compact header + grouped dropdown; `>= 720px` `204px` grouped left rail), a `Cmd/Ctrl+K` command palette, a **4-tier Settings Hub** (S1–S4), **5 official Lifecycle Hooks** (adding zero-token `PreInvocation` visual receipts), the dual-star read-only `feed-snapshot.json` contract, optional single-file `.agy-nov.json` team presets, 8 CLI commands (incl. zero-token `statusline` and read-only `recommend`), and **100% full-component 8-language UI** (`491` keys × `8` locales across all `24` components, `dist/ui/app.html` `~1.1 MB`: `English`, `简体中文`, `繁體中文`, `日本語`, `한국어`, `Español`, `Français`, `Deutsch`). Disabled modules unregister immediately from `tools/list` (`0` token & tool-slot tax against the 100-tool hard limit) and short-circuit hooks in O(1).

## Core Entry Tools (Always Available — 2 Model Tools)

- `nov_open`: Open the unified **agy-NOV** side-pane or global workbench (pass `module`: `hub`, `settings`, `modules`, or any of the 13 modules `review`, `guard`, `xray`, `turbo`, `radar`, `verify`, `worktree`, `spec`, `studio`, `canvas`, `mem`, `ops`, `remote`).
- `nov_status`: Inspect enabled modules, active preset, UI locale, exposed model tool count, and network isolation status.

*(All Hub and 4-tier Settings Hub management actions use App-only tools `visibility: ['app']` — model-visible tools remain strictly capped at 47 max.)*

## Team Presets (`.agy-nov.json`), Dual-Star Feed & CLI Safety Verification (8 CLI Commands)

- **Dual-Star Zero-Port Feed Contract (`feed-snapshot.json`):** Event-driven `<dataDir>/feed-snapshot.json` (`0600` atomic write, `< 64 KiB`, O(n) redacted, explicit `modules/<id>/` paths, zero mkdir/writes when `dataDir` is missing) enables zero-port read-only telemetry consumption by companion `agy-Sag` (see `docs/DUAL-STAR-CONTRACT.md` & `docs/PRODUCT-IA.md`).
- **5 Official Hooks (`hooks.json`):** `SessionStart` (5s), `PreToolUse` (28s), `PostToolUse` (5s), `PreInvocation` (5s — zero model tokens via `systemMessage: ""` + `metadata.user_markdown`, non-blocking, O(1) short-circuit), and `Stop` (20s).
- **Optional Single-File Team Preset (`.agy-nov.json`):** Place an optional `.agy-nov.json` at workspace root to share recommended presets, offline modules, and static verify command allowlist entries (`<= 64 KiB`, `realpath`-bounded, prototype-pollution-safe, 23-executable static allowlist with zero auto-execution, never silently enables `remote`, and never auto-creates directories). Validated read-only by `agy-nov recommend`.
- **Presets (exact model tool counts incl. `nov_open` + `nov_status`, all 47 canonical tool names unchanged):** `minimal` (1 mod / 6 tools), `core` *(default, 3 mods / 12 tools)*, `power` (9 mods / 32 tools), `local-all` (12 offline mods / 43 tools), `full` (13 mods incl. `remote` / 47 tools).
- Read-only stack scanner & `.agy-nov.json` team preset validation (zero writes): `node dist/cli.cjs recommend [--workspace=<dir>] [--json]`
- Read-only health check: `node dist/cli.cjs doctor`
- Inspect status & tool count: `node dist/cli.cjs status`
- Zero-token CLI status line (incl. `Spec:LOCK(done/total)`): `node dist/cli.cjs statusline [--compact] [--json]`
- Switch presets: `node dist/cli.cjs preset <minimal|core|power|local-all|full>`
- Toggle single module: `node dist/cli.cjs enable|disable <review|guard|xray|turbo|radar|verify|worktree|spec|studio|canvas|mem|ops|remote>`
- Switch plugin UI language: `node dist/cli.cjs locale <auto|en|zh-CN|zh-TW|ja|ko|es|fr|de>`
- Guardrails: Never enable `remote` without explicit user consent (it stays strictly inert with zero ports, zero polling, zero outbound calls, and zero writes while OFF). Respect `requireUiApproval` on `spec`, never auto-execute `.agy-nov.json` commands or silently enable `remote` (including during Settings Hub JSON config import), and disable on-demand `studio` after debugging to keep tool budgets lean.
