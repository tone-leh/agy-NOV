# agy-NOV — 100% Native Modular Super-Workbench for Antigravity 2.0

`agy-NOV` (v1.0.1, full **macOS / Windows / Linux** native cross-platform compatibility verified on a 3-OS × Node 20/22 CI matrix) unifies 13 high-demand Google Antigravity 2.0 workflows into one strictly official native plugin (Zero ASAR, Zero CDP) organized by a **4+1 functional domain IA** (Core Essentials `core` / Engineering Pipeline `pipeline` / On-Demand Toolbox `toolbox` / Opt-In Connectivity `connectivity` + **L0 Workflow Hub**), featuring **Ops 3.0** static security auditing (`prompt-injection`, `broad-command-allow`, `risky-hook`, `mcp-unsafe-env`) + cross-client deduplication preview + SettingsHub S4 **Tool-Slot Idle Advisor**, **Mem 3.0** memory hygiene with confidence tiers & TTL governance, customizable 9-segment CLI `statusline --segments` & preview-then-confirm `recommend --export-preset` `.agy-nov.json` scaffolding, an end-to-end **Engineering Pipeline Loop (`Spec → Worktree → Two-Stage Review → Verify → Mem`)**, **One-Click Clean Fork** anti-context-rot session continuation, **5 official on-demand Skills** (`agy-nov` plus `/nov-spec`, `/nov-debug`, `/nov-review`, `/nov-handoff`), **2 read-only specialist subagents** (`nov-blind-reviewer`, `nov-security-auditor`, zero default resident `rules/AGENTS.md` bloat), an official MCP Apps **`file` native custom file viewer** (`app_nov_file_viewer`, hidden from models), **Remote 2.5** structured risk approval cards, adaptive wide/narrow navigation (`< 720px` 4-control compact header + grouped dropdown; `>= 720px` `204px` grouped left rail), a `Cmd/Ctrl+K` command palette, a **4-tier Settings Hub** (S1–S4, with 6 S3 policy drawers & S4 Tool-Slot Idle Advisor), **5 official Lifecycle Hooks** (incl. zero-token `PreInvocation` visual receipts, `PreToolUse.overwrite` & `force_ask`), the dual-star read-only `feed-snapshot.json` contract, **9 CLI commands** (`doctor` verifying all **15** core plugin assets), and **100% full-component 8-language UI** (all `24` components, `dist/ui/app.html` `~1.23 MiB`, measured `1,261.2 KB`: `English`, `简体中文`, `繁體中文`, `日本語`, `한국어`, `Español`, `Français`, `Deutsch`). Disabled modules unregister immediately from `tools/list` (`0` token & tool-slot tax against the 100-tool hard limit) and short-circuit hooks in O(1).

## Core Entry Tools (Always Available — 2 Model Tools)

- `nov_open`: Open the unified **agy-NOV** side-pane or global workbench (pass `module`: `hub`, `settings`, `modules`, or any of the 13 modules `review`, `guard`, `xray`, `turbo`, `radar`, `verify`, `worktree`, `spec`, `studio`, `canvas`, `mem`, `ops`, `remote`).
- `nov_status`: Inspect enabled modules, active preset, UI locale, exposed model tool count, and network isolation status.

*(All Hub, Settings Hub, Context Pack, Dep Inspect, Turn Rewind, Turbo preferences, Clean Fork (`app_xray_build_clean_fork_pack`), `.worktreeinclude` preview (`app_worktree_preview_include`), PR delivery summary (`app_verify_pr_summary`), Mem 3.0 hygiene summary & batch actions (`app_mem_get_hygiene_summary`, `app_mem_batch_hygiene`), and native `file` viewer (`app_nov_file_viewer`) actions use App-only tools `visibility: ['app']` — model-visible tools remain strictly capped at **47** max across `v0.4`–`v1.0.1`.)*

## On-Demand Slash Playbooks & Read-Only Subagents (0 MCP Tool Slots · 0 Resident Rules Bloat)

- **4 On-Demand Official Slash Playbooks (`skills/nov-*/SKILL.md`):**
  - `/nov-spec`: Spec-first planning (`full`) & Brownfield `delta` (`ADDED`/`MODIFIED`/`REMOVED`) workflow with inline UI review, draft write locking, and `mem` archival.
  - `/nov-debug`: Disciplined 4-step root-cause debugging playbook combining bounded Turbo inspection, Guard safety checkpoints, falsifiable hypotheses, and Verify/Review evidence.
  - `/nov-review`: Two-stage code review playbook covering Stage 1 Spec compliance + Stage 2 diff risk inspection across main workspaces and Worktree branches.
  - `/nov-handoff`: Anti-context-rot handoff workflow aggregating redacted X-Ray briefs, unblocked Spec `ready` tasks, code-anchored Mem decisions, and One-Click Clean Fork continuation.
- **2 Independent Read-Only Specialist Subagents (`agents/nov-*.md`, `subagent: true, mainAgent: false`):**
  - `nov-blind-reviewer` (`agents/nov-blind-reviewer.md`): Zero-history-bias two-stage code reviewer auditing code directly from disk against Spec criteria (`PASS` / `CHANGES_REQUESTED`).
  - `nov-security-auditor` (`agents/nov-security-auditor.md`): Independent OWASP & local-agent red-team security auditor producing evidence-backed `Critical / High / Medium / Low` findings.
  - Both subagents declare strictly read-only tools (`read_file`, `grep_search`, `find_by_name`, `list_dir`) and never mutate files or execute commands.

## Native MCP Apps `file` Custom File Viewer (0 Model Tool Tax)

- `app_nov_file_viewer` registers the official `com.google.antigravity/ui` `file` entrypoint for `.sqlite`, `.sqlite3`, `.db`, `.csv`, `.tsv`, `.svg`, `.openapi.yaml`, and `.openapi.yml`.
- Completely hidden from model tool lists (`visibility: ['app']`), enforces strict canonical `realpath` containment, SVG XSS sanitization, and safe read-only fallback for opaque `antigravity-file://` URIs, and remains usable even when `studio` and `canvas` are toggled off.

## Team Presets (`.agy-nov.json`), Dual-Star Feed & CLI Safety Verification (9 CLI Commands)

- **Dual-Star Zero-Port Feed Contract (`feed-snapshot.json`):** Event-driven `<dataDir>/feed-snapshot.json` (`0600` atomic write, `< 64 KiB`, O(n) redacted, explicit `modules/<id>/` paths, zero mkdir/writes when `dataDir` is missing) enables zero-port read-only telemetry consumption by companion `agy-Sag` (see `docs/DUAL-STAR-CONTRACT.md` & `docs/PRODUCT-IA.md`).
- **5 Official Hooks (`hooks.json`):** `SessionStart` (5s), `PreToolUse` (28s — strict precedence: `guard` `deny`/`force_ask`/`ask` > `spec` `deny` > `remote` > `turbo` Auto-RTK `overwrite`), `PostToolUse` (5s — incl. - **Optional Single-File Team Preset (`.agy-nov.json`) & Preview-Then-Confirm Scaffold:** Place an optional `.agy-nov.json` at workspace root to share recommended presets, offline modules, and static verify command allowlist entries (`<= 64 KiB`, `realpath`-bounded, prototype-pollution-safe, 23-executable static allowlist with zero auto-execution, never silently enables `remote`, and never auto-creates directories). `agy-nov recommend --export-preset` strictly previews the generated scaffold read-only by default (zero writes, never writes `remote`), writing atomically only when `--confirm` is explicitly supplied (`--force` required to overwrite, symlink targets hard-rejected) with immediate post-write self-validation.
- **Presets (exact model tool counts incl. `nov_open` + `nov_status`, all 47 canonical tool names strictly unchanged):** `minimal` (1 mod / 6 tools), `core` *(default, 3 mods / 12 tools)*, `power` (9 mods / 32 tools), `local-all` (12 offline mods / 43 tools), `full` (13 mods incl. `remote` / 47 tools).
